# video_streaming_10G_SFP_imx900
Video streaming platform based on the Efinix 10G video streaming demo, this demo uses the STM135-C carrier board.  This platform accepts a MIPI input via the SOM6 MIPI RX connector and and produces video packets over the SFP+ connector.  A 10G NIC card is required to view the video stream hosted on a PC.
